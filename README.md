# url-ad

Paste a product URL → nine static ads with **Krea 2 Identity Edit** via the same `headswap_V2` Drive setup as face-swap (no HF token cell).

## Colab

[Open in Google Colab](https://colab.research.google.com/github/malihashar/url-ad/blob/main/colab/url_to_ads_krea2.ipynb)

1. Runtime → GPU  
2. Mount Drive when prompted (reuses `/content/drive/MyDrive/headswap_V2/models` if you already ran face-swap)  
3. Run all — demo Shopify URL is prefilled

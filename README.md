# url-ad

Prototype: **URL → nine static ads** with open-weight **Krea 2 Turbo** (no Magic Hour API, no Ideogram).

## Colab (run this)

[Open in Google Colab](https://colab.research.google.com/github/malihashar/url-ad/blob/main/colab/url_to_ads_krea2.ipynb)

Notebook: [`colab/url_to_ads_krea2.ipynb`](colab/url_to_ads_krea2.ipynb)

1. Runtime → GPU  
2. HF token with access to [`krea/Krea-2-Turbo`](https://huggingface.co/krea/Krea-2-Turbo)  
3. Run all cells (demo Shopify URL is prefilled)
